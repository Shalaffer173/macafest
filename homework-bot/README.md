# Щоденник — Telegram-бот с домашкой, расписанием и оценками из «Єдиної Школи»

Мини-приложение в Telegram с тремя вкладками: домашние задания одним списком с галочками и прогрессом,
расписание по неделям и оценки по предметам. Бот раз в полчаса перечитывает дневник за последние 35 дней
и на две недели вперёд (раз в сутки — весь учебный год с 1 сентября) и пишет, если появилось новое задание
или оценка, если задание изменили или добавили задним числом.

Никаких ответов и ИИ: только то, что есть в дневнике, галочки и уведомления.

## Что умеет

**Домашка**
- Список по дням: «Прострочено», «Сьогодні», «Завтра» и дальше.
- Галочки «сделано» хранятся в боте и не зависят от дневника.
- Задание, по которому в дневнике сдан ответ (текст или файлы), отмечается сделанным само.
- Прогресс: сколько сделано и сколько осталось.
- Метки «додано заднім числом», «змінено», «прибрано вчителем». Изменённое задание снова становится несделанным.
- Задания, которые уже прошли к моменту первого входа, лежат в архиве во вкладке «Усі».
- Фильтр предметов: любой предмет можно скрыть из списка и из прогресса; выбор хранится на сервере.
- Задания без текста тоже показываются: в дневнике на них можно сдать ответ.
- **Сдача ответа прямо из приложения**: кнопка «Здати» открывает задание, там можно написать текст и прикрепить
  файлы (до 20 МБ каждый). Ответ сохраняется в самом дневнике, его видит учитель. Пока учитель не проверил работу,
  ответ можно менять; после проверки дневник его блокирует.
- Файлы учителя и свои прикреплённые файлы открываются из приложения по ссылке, действующей пять минут.

**Розклад**
- Уроки по дням недели: номер, время, кабинет, учитель, тема.
- Отменённые уроки и замены помечены; метка «ДЗ» показывает, что на урок есть задание.
- Переключение недель: прошлая, текущая и две следующие.

**Оцінки** — устроены как раздел успеваемости в приложении «Єдиної Школи»
- Число пропусков за год и за текущий месяц.
- Список предметов с ожидаемой оценкой за семестр, от высокой к низкой.
- Страница предмета: средний балл за последний месяц с оценками, за семестр и за год; по месяцам — график,
  оценки с датой и видом работы, тематические отдельно с названием темы.
- Средний балл считается так же, как на сайте дневника: по текущим оценкам, а если их нет — по тематическим.
- Пять последних оценок.

**В чате с ботом**
- Уведомления о новых, изменённых и добавленных задним числом заданиях и о новых оценках.
- Вечерняя сводка в 18:00 по Киеву: что задано на следующий учебный день и ещё не сделано. `/digest` выключает и включает её.
- `/today` и `/tomorrow` — расписание на сегодня и на следующий учебный день.

`/delete` в боте или «Вийти і стерти мої дані» в приложении удаляют токен, задания, расписание и оценки.

## Как устроен вход

Пароль вводится один раз в мини-приложении (не в чате), уходит на сервер, используется для входа
и нигде не сохраняется и не пишется в журнал. Сохраняются только токены сессии
(`session_token`, `refresh_token`, `application_token`), зашифрованные AES-256-GCM ключом `SECRET_KEY`.
Когда токен истекает, бот продлевает его сам, а если не выходит — просит войти заново.

## Что проверено и что нет

Официального API у «Єдиної Школи» нет. Адреса и форматы взяты из кода сайта
`diary.eschool-ua.com` в ноябре 2026 года (см. `src/eschool.js`).

- **Вход, продление сессии и загрузка заданий** проверены на настоящем аккаунте ученика командой `npm run check`.
- **Бот и мини-приложение в Telegram** запускались на настоящем аккаунте: вход, список, галочки, загрузка за весь год.
- **Расписание и оценки** запускались на настоящем аккаунте. Известное расхождение: число пропусков за год
  отличалось от официального приложения на 2 (54 против 56); причина пока не найдена. При полной синхронизации бот
  пишет в журнал сводку по пропускам (`[sync] … пропуски {…}`), по ней это можно разобрать.
- **Открытие файлов** написано по коду сайта (файлы берутся через `/fs` на домене дневника) и на настоящем аккаунте
  не проверено: если дневник отдаёт файлы иначе, в журнале появится строка `[file]`.
- **Вечерняя сводка и команды бота** проверены тестами и на вымышленных данных; в настоящем Telegram ещё не запускались.
- **Сдача ответов** написана по коду сайта (те же запросы: `UploadFile`, `AssignAnswer`, `UpdateAnswer`, `RemoveFile`)
  и покрыта тестами на формат запросов, но в настоящий дневник ещё ни разу не отправляла. Первый раз стоит
  проверить на неважном задании и убедиться в официальном приложении, что ответ и файл появились.
- **Фоновые уведомления** (новое задание, новая оценка) на настоящем аккаунте ещё не наблюдались.
- Сколько живёт токен продления, неизвестно: это покажет только работа бота в течение нескольких дней.
- Сайт могут обновить, и клиент перестанет работать. Первым делом тогда запустить `npm run check`: он печатает каждый запрос и ответ сервера.
- Автоматический доступ может противоречить правилам сервиса. Прежде чем раздавать бота другим,
  стоит прочитать оферту на eschool-ua.com или спросить поддержку.
- Работает только с аккаунтом ученика, не родителя.

## Запуск

Нужен Node.js 22.9 или новее. Зависимостей нет.

Посмотреть приложение без Telegram и без аккаунта, на вымышленных заданиях:

```sh
npm run demo        # затем открыть http://localhost:8080, логин и пароль любые
```

Настоящий запуск:

1. Создать бота у [@BotFather](https://t.me/BotFather) и получить токен.
2. Разместить сервер на хостинге с HTTPS (Mini App открывается только по HTTPS).
3. Скопировать `.env.example` в `.env` и заполнить `BOT_TOKEN`, `PUBLIC_URL`, `SECRET_KEY` (`openssl rand -hex 32`).
   Файл `.env` в git не попадает.
4. `npm start`. Бот сам ставит кнопку меню «Домашка», которая открывает приложение.

База — один файл SQLite (`DB_PATH`). Если потерять `SECRET_KEY`, всем придётся войти заново.

## Запуск на своём компьютере без хостинга

```sh
npm run tunnel      # бот + бесплатный тоннель localhost.run, адрес подхватывается сам
npm run autostart   # то же, но службой: стартует при входе в систему и перезапускается при сбое
```

Тоннель часто меняет адрес, поэтому приложение нужно открывать кнопкой меню «Домашка» в чате с ботом:
бот обновляет её при каждом перезапуске. Бот работает, только пока компьютер включён.

## Устройство

- `src/eschool.js` — клиент дневника: вход, продление сессии, загрузка уроков и разбор их в задания, расписание и оценки,
  чтение и отправка ответов на задания.
- `src/sync.js` — сравнение свежих данных с сохранёнными, хранение расписания и оценок, текст уведомлений.
- `src/server.js` — HTTP-сервер: API приложения, раздача `web/`, фоновая синхронизация.
- `src/telegram.js` — бот на long polling с командами.
- `src/digest.js` — тексты для чата: расписание на день и вечерняя сводка.
- `src/crypto.js` — шифрование сессий и проверка подписи Telegram.
- `src/demo.js` — вымышленный дневник для `DEMO=1`.
- `web/` — мини-приложение.
