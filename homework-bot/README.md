# Домашка — Telegram-бот со списком заданий из «Єдиної Школи»

Мини-приложение в Telegram: все домашние задания одним списком с галочками и прогрессом.
Бот раз в полчаса перечитывает дневник за последние 35 дней и 14 дней вперёд и пишет,
если появилось новое задание, если его изменили или добавили задним числом.

Никаких ответов и ИИ: только список, галочки и уведомления.

## Что умеет

- Список по дням: «Прострочено», «Сьогодні», «Завтра» и дальше.
- Галочки «сделано» хранятся в боте и не зависят от дневника.
- Прогресс: сколько сделано и сколько осталось.
- Метки «додано заднім числом», «змінено», «прибрано вчителем». Изменённое задание снова становится несделанным.
- `/delete` в боте или «Вийти і стерти мої дані» в приложении удаляют токен и все задания.

## Как устроен вход

Пароль вводится один раз в мини-приложении (не в чате), уходит на сервер, используется для входа
и нигде не сохраняется и не пишется в журнал. Сохраняются только токены сессии
(`session_token`, `refresh_token`, `application_token`), зашифрованные AES-256-GCM ключом `SECRET_KEY`.
Когда токен истекает, бот продлевает его сам, а если не выходит — просит войти заново.

## Что проверено и что нет

Официального API у «Єдиної Школи» нет. Адреса и форматы взяты из кода сайта
`diary.eschool-ua.com` в ноябре 2026 года (см. `src/eschool.js`).

- **Вход, продление сессии и загрузка заданий** проверены на настоящем аккаунте ученика командой `npm run check`.
- **Бот в Telegram и фоновые уведомления** на настоящем аккаунте ещё не запускались.
- Сколько живёт токен продления, неизвестно: это покажет только работа бота в течение нескольких дней.
- Сайт могут обновить, и клиент перестанет работать. Первым делом тогда запустить `npm run check`: он печатает каждый запрос и ответ сервера.
- Автоматический доступ может противоречить правилам сервиса. Прежде чем раздавать бота другим,
  стоит прочитать оферту на eschool-ua.com или спросить поддержку.
- Работает только с аккаунтом ученика, не родителя.

## Запуск

Нужен Node.js 22.9 или новее. Зависимостей нет.

Посмотреть приложение без Telegram и без аккаунта, на вымышленных заданиях:

```sh
npm run demo        # затем открыть http://localhost:8080, логин и пароль любые
```

Настоящий запуск:

1. Создать бота у [@BotFather](https://t.me/BotFather) и получить токен.
2. Разместить сервер на хостинге с HTTPS (Mini App открывается только по HTTPS).
3. Скопировать `.env.example` в `.env` и заполнить `BOT_TOKEN`, `PUBLIC_URL`, `SECRET_KEY` (`openssl rand -hex 32`).
   Файл `.env` в git не попадает.
4. `npm start`. Бот сам ставит кнопку меню «Домашка», которая открывает приложение.

База — один файл SQLite (`DB_PATH`). Если потерять `SECRET_KEY`, всем придётся войти заново.

## Устройство

- `src/eschool.js` — клиент дневника: вход, продление сессии, загрузка уроков с заданиями.
- `src/sync.js` — сравнение свежего списка с сохранённым и текст уведомлений.
- `src/server.js` — HTTP-сервер: API приложения, раздача `web/`, фоновая синхронизация.
- `src/telegram.js` — бот на long polling.
- `src/crypto.js` — шифрование сессий и проверка подписи Telegram.
- `src/demo.js` — вымышленный дневник для `DEMO=1`.
- `web/` — мини-приложение.
