# Доставка — экран заказа курьера

Веб-приложение для телефона: тёмная карта с метками и нижняя панель с данными заказа, в которой можно поменять любой текст.

## Как пользоваться

- **Редактирование.** Нажмите на строку панели, откроется окно с полями:
  - «Доставлено через 22 хв»: минуты (это же число показывается на зелёной метке), текст перед ними и единица времени;
  - имя заказчика вместе с кодом заказа (`#` добавляется сам);
  - «Товари (3)»: количество и надписи;
  - адрес, инструкции, примечание и их заголовки;
  - зелёная надпись «Перекласти».
- **Панель.** Тяните за белый ползунок вверх или вниз (можно и за любое место панели).
- **Синяя метка.** Нажмите верхнюю правую кнопку, затем место на карте.
- **Зелёная метка с временем.** Нажмите кнопку под ней, затем место на карте. Между метками рисуется зелёная линия.
- Повторное нажатие на кнопку или на подсказку внизу отменяет установку метки.
- **Карта** не сдвигается пальцем, её можно только приближать и отдалять: щипком двумя пальцами или двойным касанием. Чтобы перейти в другой район, отдалите карту и приблизьте её в нужном месте.
- Кнопка меню (три полоски) ничего не делает.
- Все изменения хранятся на телефоне и остаются после перезапуска.

## Как открыть на телефоне

Это статический сайт: `index.html`, JS и CSS, без сборки. Ему нужен любой хостинг с HTTPS.

- **GitHub Pages.** Settings → Pages → Build and deployment → Source: *Deploy from a branch* → ветка с приложением, папка `/ (root)` → Save. Через пару минут сайт откроется по адресу `https://shalaffer173.github.io/macafest/`. Бесплатно Pages работает только для публичных репозиториев, для приватных нужен GitHub Pro.
- **Netlify, Cloudflare Pages или Vercel** бесплатно работают и с приватным репозиторием: импортируйте его, команду сборки не указывайте, папка публикации — корень.

Потом в Chrome откройте меню ⋮ и выберите «Установить приложение» или «Добавить на главный экран». Приложение будет открываться на весь экран, без адресной строки.

## Запуск на компьютере

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Если открыть `index.html` двойным щелчком, ничего не заработает: браузер не загружает модули с `file://`.

## Устройство

- `index.html` — разметка, `style.css` — оформление (размеры сняты со скриншотов экрана шириной 393 dp).
- `app.js` — редактирование, панель, метки, сохранение в `localStorage`.
- `map-style.js` — тёмный стиль карты. Язык подписей задаётся в `LABEL_LANG`: где есть перевод, подписи русские, иначе местные.
- Карта: [MapLibre GL JS](https://maplibre.org/) и векторные тайлы [OpenFreeMap](https://openfreemap.org/) (данные © участники OpenStreetMap). Если OpenFreeMap недоступен, автоматически включается тёмная растровая карта CARTO.
- `manifest.webmanifest` и `icons/` нужны для установки на главный экран.
